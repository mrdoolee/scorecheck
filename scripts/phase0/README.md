# Phase 0 — 학교 노트북 환경 검증

학생 데이터를 쓰지 않는 시험이다. 목적은 "폰 → PC 핫스팟 → PC 로컬 서버"로 서명이 실제로 전달되는지 확인하는 것이다.

## 이미 확인한 것 (2026-10-28, 개발 노트북)

| 항목 | 결과 |
| --- | --- |
| 핫스팟 기능 사용 가능 여부 (`hotspot.ps1 status`) | 가능 (`capability = Enabled`), 공유 연결 = 학교 Wi-Fi |
| 사용자 계정 예약 작업 등록·실행·삭제 (`task-test.ps1`) | 관리자 권한 없이 성공 |
| 시험 서버 기능 (로컬 주소로 시험) | 페이지 200, 그 외 경로 404, 잘못된 토큰 403, 중복 제출 1회만 저장 |
| node.exe 방화벽 규칙 | 개인(Private) 네트워크만 허용. 핫스팟 쪽은 아직 모름 |

## 교사가 할 시험 (약 30분)

프로젝트 폴더에서 PowerShell을 연다.

1. 핫스팟 켜기

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\phase0\hotspot.ps1 start
   ```

   `"state":"On"`이 나오면 성공. 함께 나오는 `ssid`, `passphrase`로 폰을 연결한다.

2. 폰을 핫스팟에 연결하고, 노트북에서 인터넷 사이트가 계속 열리는지 확인한다.

3. 시험 서버 실행

   ```powershell
   node scripts\phase0\server.mjs
   ```

   - 화면에 나온 `http://192.168.137.x:8765/s/xxxxxx` 주소를 폰 브라우저에 입력한다.
   - Windows 방화벽 창이 뜨면 **허용**을 누른다. (시험 후 정리 방법은 아래)

4. 폰에서 서명 → [보내기] → "PC 저장 완료"가 뜨는지 확인한다. 노트북 창에 `[저장]` 줄이 나오고 `scripts\phase0\out\`에 `.svg` 파일이 생겨야 한다.

5. 노트북에서 `Ctrl+C`로 서버를 끄고, 폰에서 새로고침했을 때 접속이 안 되는지 확인한다.

6. 핫스팟 끄기

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\phase0\hotspot.ps1 stop
   ```

## 안 될 때

- 서버가 "핫스팟 어댑터 주소를 찾지 못했습니다"라고 하면: 핫스팟이 켜져 있는지 확인. 나온 주소 목록을 기록한다.
- 폰에서 페이지가 안 열리면: 방화벽 창을 놓쳤거나 차단으로 눌렀을 가능성이 크다. 기록만 하고 넘어간다(정책을 우회하지 않는다).
- 시험 후 `out\` 폴더는 지워도 된다.
