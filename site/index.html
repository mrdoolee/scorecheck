학생은 본인 성적만 봅니다

학생 화면에는 점수, 학급·학년 평균과의 차이, 문항별 결과와 문항마다 전체 정답률, 짧은 피드백 한 줄이 나옵니다. 이름 바로 아래에 나이스 일람표 원본의 본인 줄이 함께 나와 무엇에 서명하는지 바로 보입니다.

  • 석차·등수·백분위는 만들지도, 보여 주지도 않습니다.
  • 다른 학생의 정보는 화면에 나오지 않습니다.
  • 학생 화면은 전체 화면으로 고정됩니다. 창 닫기·새로 고침 단축키도 막힙니다.

서명은 선생님 휴대폰에 손으로

선생님의 휴대폰이나 태블릿 PC를 서명 패드로 씁니다. QR 두 번이면 연결됩니다. 첫 번째 QR로 노트북 핫스팟에 접속하고, 두 번째 QR로 서명 페이지를 엽니다. 학생이 [서명하기]를 누르면 휴대폰에 서명 칸이 뜨고, 위쪽에 일람표 본인 줄이 같이 나옵니다.

  • 서명은 비고칸 크기에 맞춰 얹습니다. 나이스 양식은 고치지 않습니다.
  • 다시 받아야 하면 [다시 서명하기]. 마지막 서명만 남습니다.
  • 휴대폰 연결이 안 되는 날에는 PC 화면에 직접 서명할 수도 있습니다.

학교망도 인터넷도 거치지 않습니다

서명 데이터는 노트북과 서명용 휴대폰 사이에서만 오갑니다.

노트북이 켠 모바일 핫스팟(WPA2 암호)에 선생님 휴대폰을 직접 연결합니다. 학교망, 인터넷, 외부 서버를 지나지 않습니다. 몇점은 서버, 클라우드, 외부 AI, 통계 수집, 자동 업데이트를 쓰지 않습니다.

휴대폰으로 가는 것
반·번호, 가운데를 가린 이름, 일람표 본인 줄 그림(머리글과 본인 행. 이 줄의 이름·점수가 보입니다)뿐입니다. 다른 학생 정보는 가지 않습니다.
휴대폰이 보내는 것
서명 획의 좌표뿐입니다. 휴대폰에는 성적과 서명을 저장하지 않습니다.

AES-256-GCM으로 암호화해 둡니다. 같은 PC의 같은 Windows 계정에서만 열립니다.
연결 주소
실행할 때마다 새로 만드는 임의 토큰이 들어가고, 핫스팟 주소에서만 열립니다.

설치와 준비물

준비물

  • Windows 노트북 또는 PC. 무선랜이 있어 모바일 핫스팟을 켤 수 있어야 합니다.
  • 서명 패드로 쓸 안드로이드 휴대폰이나 태블릿 PC와 크롬
  • 나이스에서 내려받은 성적 파일 정기고사: 반별 학생답 정오표(xlsx), 반별 교과목별 일람표(PDF), 학년 전체 교과목별 일람표(xlsx, 선택) 수행평가: 반별 강의실별 일람표(xlsx)와 PDF

노트북이 학교 Wi-Fi나 유선에 연결된 상태에서 핫스팟을 켭니다. 서명 데이터는 노트북과 휴대폰 사이에서만 오가고, 학교망이나 인터넷으로 나가지 않습니다.

무선랜이 없는 PC는 핫스팟을 켤 수 없습니다. 이때는 PC 화면에 직접 서명합니다.

설치 순서

  1. 받은 ScoreCheck-Setup 파일을 실행합니다. 관리자 권한 없이 현재 사용자에게 설치됩니다.
  2. 「Windows의 PC 보호」 창이 뜨면 추가 정보 → 실행을 누릅니다. 코드 서명이 아직 없어서 뜨는 창입니다.
  3. 바탕화면의 몇점을 실행합니다.
  4. 처음 휴대폰을 연결할 때 Windows 방화벽 창이 뜨면 허용합니다.
  5. 안드로이드 기기는 처음 한 번 설정 → 애플리케이션 → Chrome → 권한 → 근처 기기 → 허용을 해 둡니다.

자주 묻는 질문

학교 업무망에서도 되나요?

업무망에 연결된 학교 노트북에서 확인했습니다. 학교마다 무선·핫스팟 정책이 달라 안 될 수 있습니다. 핫스팟을 켤 수 없으면 PC 화면에 직접 서명할 수 있습니다.

아이폰·아이패드로도 서명할 수 있나요?

안드로이드 크롬에서 확인했고, 아이폰·아이패드는 아직 확인하지 못했습니다.

어떤 나이스 양식을 쓸 수 있나요?

중학교 나이스 정기고사 교과목별 일람표·수행평가 강의실별 일람표로 확인했습니다. 고등학교 양식은 아직 확인 전입니다. 학교, 학년, 반 수, 과목, 문항 수는 정해 두지 않아 파일에 있는 대로 읽습니다.

휴대폰에서 서명 페이지가 안 열려요.

ERR_TOO_MANY_RETRIES가 뜨면 안드로이드 크롬의 근처 기기 권한이 꺼져 있는 경우입니다. 설정 → 애플리케이션 → Chrome → 권한 → 근처 기기를 허용하세요. 휴대폰이 노트북 핫스팟에 연결됐는지, 방화벽을 허용했는지도 확인하세요. 그래도 안 되면 PC 화면에 서명합니다.

설치할 때 경고 창이 떠요.

아직 코드 서명이 없어 「Windows의 PC 보호」 창이 뜰 수 있습니다. 추가 정보 → 실행을 누르면 설치됩니다.

학생 정보는 어디에 저장되고, 언제 지워지나요?

선생님 PC의 Windows 사용자 폴더에 암호화해 저장하고, 선생님이 지울 때까지 남습니다. 첫 화면 「이전 작업」에서 [서명 삭제](받은 서명만) 또는 [작업 삭제](성적·서명·문항정보·원본 사본 전부)로 지웁니다. 만든 지 30일이 지난 작업에는 정리 권장 표시가 붙고, 앱을 제거하면 앱에 저장된 데이터도 함께 지워집니다.

석차는 왜 안 보이나요?

학생에게는 본인 점수와 평균과의 차이까지만 보여 주기로 했습니다. 몇점은 석차·등수·백분위를 어떤 화면과 파일에도 만들지 않습니다.
